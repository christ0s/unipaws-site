### Team Photos (optional)

### Partner Logos (optional)

### General
- `logo.png` - UniPaws logo (for favicon and sharing)
- `og-image.png` - Open Graph image for social sharing (1200x630px)
- `favicon.ico` - Website favicon (32x32px)

## Image Guidelines

1. **Format**: Use PNG for logos/icons, JPEG for photos
2. **Optimization**: Compress all images before upload
3. **Retina**: Provide 2x versions where possible
4. **Alt text**: Always add descriptive alt text in HTML
